# На одной луне · Pokitalk

[⬇ Скачать демо для Android · APK, 4 МБ](https://github.com/einerfriedmann/pokitalk/raw/refs/heads/main/download/pokitalk-demo.apk)

Версия 0.2.0: маленький питомец на весь главный экран. В центре — лунный кот Люми, его эмоции и пузыри с незнакомыми словами. Наверху четыре шкалы: сытость, вода, сон, настроение; отдельно — доверие. Внизу только уход и карточки-подсказки. Это оригинальный персонаж и оформление; от Pou взят простой цикл заботы о питомце.

## Как играть

При первом запуске выбирается язык обучения (в демо доступен немецкий), затем один раз показывается встреча с котом. Дальше название языка не появляется в истории. Люми выражает настроение и просьбы словами из колоды пользователя.

Коснитесь пузыря или кнопки ответа: предложите коту еду, воду, отдых или игру. Готовые действия даны по-русски: нужно понять слово в просьбе. В режиме букв нужно вспомнить и собрать немецкое слово. По умолчанию каждый третий ход использует буквы; формат можно изменить в настройках. Карточки открываются поверх комнаты, не расходуют доверие и помогают понять настроение и просьбу.

- Точное исполнение просьбы: доверие +6, нужная шкала +28 перед затратой 2 на ход, слово добавляется в изученные.
- Другая забота того же типа: доверие +2, нужная шкала +14 перед затратой 2, слово не считается выученным.
- Неподходящая забота: доверие −6, исходная потребность остаётся неудовлетворённой.
- «Не сейчас»: доверие −3, потребности −4.
- Неверно собранное слово: доверие −2; можно открыть карточку и исправиться.
- Касание кота — поглаживание: +2 доверия. Если он очень устал, −2. Повторные касания чаще 15 секунд не дают очков.

Потребности теряют 1 пункт за 15 минут, максимум 16 за отсутствие. Доверие за время отсутствия не снижается. Кот не умирает. Прогресс хранится на устройстве; сеть для игры не нужна. Версия 0.1 переносит уже изученные слова без повторного приветствия. Доверие и шкалы ограничены 0–100. Поведение проверено в браузере; реальный Android-телефон и эмулятор пока не проверены.

## Запуск и проверки

Нужны Node.js 22.12+ (проверено на 24) и npm:

```sh
npm ci
npm run dev
```

`npm test` — 13 проверок правил игры, миграции и происхождения слов. `npm run build` — веб-сборка. При работающем dev-сервере `node scripts/smoke.mjs` проверяет первый запуск, отсутствие повторного приветствия, последствия действий, буквы, бесплатные подсказки, сохранение, миграцию и мобильные размеры в `/usr/bin/chromium`.

## Android

Проект Capacitor: `android/`, Android 7+ / API 24, JDK 21 с `javac`, SDK 36. В подготовленной cloud-среде доступны SDK `/workspace/android-sdk`, полный JDK `/workspace/jdk-21` и кеш Gradle `/workspace/.gradle`.

```sh
npm run android:sync
python scripts/build_android.py
```

Скрипт использует наследуемый сетевой прокси и системное хранилище CA. На своей машине можно указать `ANDROID_HOME` и `JAVA_HOME`, а затем выполнить `cd android && ./gradlew assembleDebug`. Результат — `android/app/build/outputs/apk/debug/app-debug.apk`. Код версии 2 позволяет установить обновление поверх первой демки при той же подписи. Это отладочная сборка.

## Словарь

Колода пользователя `Oxford_3000_Englisch-Deutsch.apkg` содержит 4055 пар английский–немецкий. `data/source-deck.json` хранит извлечённые пары и SHA-256 исходного файла; `scripts/import_anki.py PATH` воспроизводит извлечение.

`src/deck.json` — 12 слов для ухода; `src/moods.json` — 10 слов настроения и реакций. Русские переводы добавлены для игры. Каждый немецкий элемент имеет `source_en` и `source_de`; тест проверяет его точное присутствие в исходном поле (либо отдельный вариант через запятую). Реплики составляются только из этих слов с пунктуацией. Вся колода пока не превращена в игровые задания. Импорт пользовательского JSON из первой версии убран из основного игрового цикла.

## Ограничения демо

Один кот, одна комната, короткая сцена знакомства, локальное сохранение. Пока без озвучки, магазина, мини-игр, ветвящегося сюжета и облачной синхронизации. Эмоции меняются вместе с состоянием и результатом действия. Все иллюстрации кота — оригинальная векторная графика.
