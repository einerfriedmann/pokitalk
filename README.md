# На одной луне · Pokitalk 0.3

[⬇ Скачать APK для Android 7+ · около 4 МБ](https://github.com/einerfriedmann/pokitalk/raw/refs/heads/main/download/pokitalk-demo.apk?v=0.3.0)

Оригинальная демо-игра о лунном коте Люми. Исследуй квартиру, узнавай немецкие названия знакомых вещей, понимай просьбы кота и закрепляй слова в игровом автомате. Интерфейс русский. Выбор языка и знакомство показываются один раз; в истории язык не называется.

## Квартира и обучение

Четыре комнаты: спальня, санузел, кухня, игровая. Нажатие на предмет открывает образ, существительное с артиклем (например, **der Tisch**), русский перевод и пример **Das ist der Tisch.** Предметы закрытых тем остаются частью обстановки; карточка объяснит, какое доверие нужно для открытия.

Реплики Люми — полные предложения, например **Ich bin durstig. Ich brauche Wasser.** Есть перевод-подсказка и кнопка озвучивания. Можно включить постоянный перевод в настройках. Для ответа на просьбу предложи предмет с подходящей репликой. Уход меняет сытость, воду, сон, настроение, чистоту и доверие. Выбор может помочь или обидеть кота. Подсказки бесплатны.

Словарь содержит **300 уникальных слов, 10 тем по 30**. Первая тема доступна сразу; остальные открываются при доверии 50,55,60,65,70,75,80,90,95. Ранее открытая тема не закрывается при снижении доверия. Осмотр, узнавание в мини-игре и использование в уходе учитываются отдельно. Открытие карточки само по себе не отмечает слово выученным.

## Отдельная мини-игра: «Падающие слова»

Вход — **игровой автомат в игровой комнате**. На основном экране отдельной кнопки мини-игры нет.

Раунд длится 45 секунд, есть 5 попыток. Слово с артиклем падает сверху; нажми на соответствующую картинку до падения. За серию правильных ответов скорость немного растёт. Темы: еда/напитки, бытовые приборы, кухонные принадлежности. В игре используются только уже открытые слова с различимыми образами (сейчас 9/8/10 предметов соответственно). Приборы доступны после открытия темы квартиры, кухонные вещи — после следующей темы.

Ошибки меняют только игровые попытки и серию: состояние кота и доверие не ухудшаются. За законченный раунд можно получить до 3 доверия (1 за каждые 3 попадания), начисление одноразовое. При сворачивании игра ставится на паузу. Выход до завершения не даёт награду.

## Словарь и источник

Пользователь предоставил `Oxford_3000_Englisch-Deutsch.apkg` (4055 пар английский–немецкий). `data/source-deck.json` хранит пары и SHA-256 файла. `scripts/import_anki.py PATH` воспроизводит извлечение.

- `src/curriculum.json`:300 слов, темы, русские значения, артикли, визуальные ключи и исходная пара для каждого слова.
- `src/conversations.json`:12 диалогов ухода, реакции, примеры,64 корня и их грамматические формы.
- `src/objects.js`:оригинальные векторные иллюстрации предметов без внешних ресурсов.

Каждое немецкое заглавное слово — точный вариант из исходной колоды. Для связных фраз используются обычные грамматические формы этих слов, явно сопоставленные корням (например, **bin → sein**, **möchte → mögen**). Все 64 корня реплик включены в учебные 300. Отсутствующие в источнике названия не выдумывались.

## Запуск и проверки

Нужны Node.js22.12+ (проверено на 24) и npm:

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

`npm test` — правила ухода, словарь, происхождение фраз, квартира, открытие тем и независимый движок мини-игры (47 проверок). `npm run build` — сборка приложения.

При запущенном dev-сервере:

```sh
node scripts/smoke.mjs
node scripts/smoke_falling.mjs
```

Браузерные сценарии используют `/usr/bin/chromium`:проверяют комнаты и предметы, артикли, одноразовое знакомство, миграцию сохранений, закрытые темы, последствия заботы, таймер, настоящее движение слова, паузу, три игровые темы, награду и сохранение. Chromium не проверяет нативную озвучку Android.

## Android

Проект Capacitor в `android/`; minAPI24 (Android7), compile/targetAPI36, JDK21. Нативный `MoonSpeechPlugin` использует установленный голос TextToSpeech:для немецкой озвучки нужен голос на устройстве. В браузере используется доступный немецкий голос WebSpeech; при его отсутствии приложение сообщает об этом и продолжает работать с текстом/образами.

```sh
npm run android:sync
python scripts/build_android.py
```

В подготовленной среде SDK: `/workspace/android-sdk`, полный JDK: `/workspace/jdk-21`, кеш Gradle: `/workspace/.gradle`. Скрипт наследует прокси и системное хранилище CA. На своей машине можно использовать `ANDROID_HOME`, `JAVA_HOME` и `cd android && ./gradlew assembleDebug`.

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Версия приложения 0.3.0, versionCode3. Подпись должна совпадать с предыдущими сборками для обновления без удаления. Это отладочная демоверсия. Функции на реальном телефоне/эмуляторе, в том числе установленный немецкий голос, пока не проверялись. Прогресс предыдущих версий переносится, повторного знакомства нет. Игра работает без аккаунта; данные хранятся на устройстве.

Пока нет большого сюжета, магазина, сетевых функций, облачных сохранений или интервального планировщика повторения.300 слов есть в словаре; мини-игра тренирует иллюстрируемые предметы трёх тем, а не все 300 абстрактных слов.
