# На одной луне · Pokitalk

[⬇ Скачать демо для Android · APK, 4 МБ](https://github.com/einerfriedmann/pokitalk/raw/refs/heads/main/download/pokitalk-demo.apk)

Русскоязычная демо-игра для изучения немецкого: лунный кот Люми, короткая история, учебные карточки, выбор значения и сборка слова из букв. Уход повышает доверие и самочувствие; ошибки не наказывают. Прогресс хранится локально. Сеть во время игры не нужна.

## Запуск

Node.js 22.12+ (проверено на 24), npm:

```sh
npm ci
npm run dev
```

Проверки: `npm test`, `npm run build`. При запущенном dev-сервере `node scripts/smoke.mjs` проверяет Chromium, выбор ответа, ошибку, награду, сохранение, сборку букв и мобильную ширину. Для проверки требуется Chromium (`/usr/bin/chromium`).

## Android

Проект Capacitor находится в `android/`, min Android 7 / API 24. Для сборки нужны JDK 21 (с `javac`), Android SDK 36 и Build Tools 36.0.0.

```sh
npm run android:sync
cd android
./gradlew assembleDebug
```

В подготовленной cloud-среде: `python scripts/build_android.py` (SDK в `/workspace/android-sdk`, JDK в `/workspace/jdk-21`, наследует настройки прокси).

Укажите SDK через `ANDROID_HOME` либо игнорируемый `android/local.properties`. Результат: `android/app/build/outputs/apk/debug/app-debug.apk`. Это отладочная сборка, не релиз для магазина. Проверка на реальном телефоне пока не выполнена.

## Словарь

Пользователь предоставил `Oxford_3000_Englisch-Deutsch.apkg`. В нём 4055 пар английский–немецкий. `data/source-deck.json` содержит извлечённые пары, имя файла и SHA-256; `scripts/import_anki.py PATH` воспроизводит извлечение без выполнения HTML или скриптов из карточек.

В `src/deck.json` отобраны 12 немецких слов для ухода. Поля `source_en` и `source_de` сохраняют происхождение; русский перевод добавлен для интерфейса. Тест проверяет, что каждое немецкое слово присутствует в исходной колоде (для вариантов через запятую выбран один вариант). Немецкие фразы и внешняя лексика не добавлены. Полная колода пока не включена в игровой цикл. Права на публикацию сторонней колоды нужно уточнить перед публичным распространением.

Можно заменить словарь в приложении JSON-массивом из 2–200 карточек: поля `de`, `ru`, `need` (одно из `food`, `drink`, `rest`, `play`). Замена начинает историю заново. Импорт опирается на подтверждение пользователя; автоматическая сверка импортируемых слов с исходной колодой не реализована.

## Объём демо

Один персонаж, первая сцена, 12 слов, два режима ответа. Пока без озвучки, разветвлённого сюжета, отдельных шкал потребностей, интервального повторения, аккаунтов и облачной синхронизации. Словесная просьба кота намеренно состоит только из проверенного слова; в режиме букв она скрывается до подсказки.
